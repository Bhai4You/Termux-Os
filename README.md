# Termux-Os
All in One Termux Os..!! (New)

# Installation...

1) git clone https://github.com/Bhai4You/Termux-Os

2) cd Termux-Os

3) chmod +x requirement.sh Termux-Os.sh

4) bash requirement.sh

5) bash Termux-Os.sh

[*] Enjoy Hacking....
